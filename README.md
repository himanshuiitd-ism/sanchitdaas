# Mr. Sanchit Das Portfolio

A modern Next.js + TypeScript starter for the personal portfolio website.

## Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- App Router

## Local Development

```bash
npm install
npm run dev
```

Open the app at http://localhost:3000.

## Available Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.
